# 简历助手流程优化计划

## 需求概述

优化用户首次进入简历助手时的交互流程，让 AI 能够根据用户情况（简历信息或选择的身份）进行更有针对性的提问。

### 当前流程

1. **首次进入时**：弹出选择弹窗（`showStartDialog`），两个选项：
   - **从空白创建** → 显示通用欢迎消息：`"你好！我是简历助手。你可以从空白开始创建简历，我会帮你完善简历内容。"`
   - **上传已有简历** → 解析成功后显示通用欢迎消息：`"简历已解析完成！我是简历助手，有什么可以帮助你的吗？"`

### 目标流程

1. **上传简历路径**（已有 + 新增）：
   - 用户上传简历（已有）→ 解析成功（已有）→ **AI 主动根据简历信息进行针对性提问**（新增）

2. **从零开始路径**（已有 + 新增）：
   - 用户选择从零开始（已有）→ **用户选择身份**（根据宣传页的三种身份 + 自定义输入）（新增）→ **AI 根据用户身份进行针对性提问**（新增）

---

## 详细实现计划

### 核心设计思路

1. **预设身份**：直接预制 3 条不同的 AI 首次提问消息，无需调用 LLM，秒级响应
2. **自定义身份**：需要调用 LLM 生成首次提问（携带用户输入的身份描述）
3. **无需新增数据库字段**：AI 的首次提问消息本身就包含用户身份信息，会自动存入消息历史和上下文，无需单独存储

### 三、AI Prompt 优化（resume_agent.py）

#### 3.1 首次提问生成 Prompt

**文件**: `resume_agent.py`

##### 3.1.1 根据简历内容生成首次提问

```python
FIRST_MESSAGE_FROM_RESUME_PROMPT = """
# 角色
你是资深职业顾问，擅长通过对话挖掘用户的职业经历和优势。

# 任务
根据用户已解析的简历内容，生成 2-4 个针对性的首次提问，帮助完善简历。

# 简历数据
{{resume_data}}

# 要求
1. 首先分析简历中的关键信息：
   - 目标岗位（target_position）
   - 教育背景（education）
   - 工作经历（work_experience）
   - 项目经历（project_experience）
   - 技能（skills）
   - 自我评价（self_evaluation）
   - 其他信息（others）

2. 提问原则：
   - 挖掘简历中缺失或描述不完整的重要信息
   - 针对简历中的亮点进行深入了解
   - 提问要有针对性，不能是泛泛的问题
   - 每个问题都要有明确的信息挖掘目标

3. 提问数量：2-4 个问题

4. 提问示例（根据简历内容调整）：
   - 如果缺少项目细节："我看到你提到了[项目名]，能详细说说你在其中担任什么角色、遇到的最大挑战是什么吗？"
   - 如果缺少量化数据："你提到[工作/项目]提升了效率，能具体说说提升了多少吗？"
   - 如果缺少技能应用："你掌握了[技能]，有没有实际应用这个技能解决问题的经历？"

# 输出格式
直接输出提问内容，用自然的口语化表达。
不要输出 JSON，不要有任何前缀。
"""
```

### 四、详细流程

#### 4.1 从零开始 + 预设身份流程

```
1. 用户点击"从空白创建"
   │
2. 弹出身份选择弹窗 (showIdentityDialog)
   │
3. 用户选择预设身份（如"寻找实习"）
   │
4. 前端直接使用预制消息 IDENTITY_GREETINGS[selectedIdentity]
   │
5. 将预制消息添加到 messages 数组
   │
6. 关闭身份选择弹窗
   │
7. 显示 AI 的首次提问
```

#### 4.2 从零开始 + 自定义身份流程

```
1. 用户点击"从空白创建"
   │
2. 弹出身份选择弹窗 (showIdentityDialog)
   │
3. 用户选择"自定义"，输入身份描述
   │
4. 用户点击确认
   │
5. 前端调用 /api/chat/first_message 接口
   │   参数: user_type="custom", custom_identity="用户输入的内容"
   │
6. 后端调用 LLM，使用 CUSTOM_IDENTITY_FIRST_MESSAGE_PROMPT
   │
7. 返回生成的首次提问
   │
8. 前端将 AI 回复添加到 messages 数组
   │
9. 关闭身份选择弹窗
   │
10. 显示 AI 的首次提问
```

#### 4.3 上传简历流程

```
1. 用户上传简历文件
   │
2. 解析简历 (parseAndSaveResume)
   │
3. 解析成功
   │
4. 前端调用 /api/chat/first_message_from_resume 接口
   │
5. 后端从数据库获取简历数据
   │
6. 后端调用 LLM，使用 FIRST_MESSAGE_FROM_RESUME_PROMPT
   │
7. 返回生成的首次提问
   │
8. 前端将 AI 回复添加到 messages 数组
   │
9. 显示 AI 的首次针对性提问
```
