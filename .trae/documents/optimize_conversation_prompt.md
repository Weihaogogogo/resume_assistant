# 计划：优化 CONVERSATION\_PROMPT 避免AI在工具调用后输出"已保存"类表述

## 问题分析

当AI调用 `save_resume_tool` 时，前端会弹出确认框让用户选择是否要修改。此时AI输出的文本不应该说"已经同步到简历库"、"保存到你的简历"诸如此类的话，因为这时候还需要等待用户确认。

当前 prompt 第229行已有说明：

> "调用后，系统会自动在前端显示确认框，用户点击确认后才会实际保存。"

但AI在实际回复中可能仍会说"已保存"、"已修改"之类的话，说明规则不够明确。

## 修改方案

### 1. 强化工具调用后的输出规则

在第226-229行的"确认修改"规则基础上，增加更明确的输出指引：

**修改前：**

```
3. **确认修改**：当你给出了完整的优化建议、可以达到修改标准时，调用 `save_resume_tool`。此时，你的回复内容应包含完整的修改建议（用自然语言描述），然后调用工具。

# 工具调用规则
- **save_resume_tool**：当你给出了完整的优化建议、可以达到修改标准时，需要输出完整的修改建议（不要只输出部分的改动点，而是要输出要修改的部分的前后对比），且调用此工具。你需要将完整的简历JSON作为参数传入。调用后，系统会自动在前端显示确认框，用户点击确认后才会实际保存。
```

**修改后：**

```
3. **确认修改**：当你给出了完整的优化建议、可以达到修改标准时，调用 `save_resume_tool`。此时，你的回复内容应包含完整的修改建议（用自然语言描述），然后调用工具。

# 工具调用规则
- **save_resume_tool**：当你给出了完整的优化建议、可以达到修改标准时，需要输出完整的修改建议（不要只输出部分的改动点，而是要输出要修改的部分的前后对比），且调用此工具。你需要将完整的简历JSON作为参数传入。调用后，系统会自动在前端显示确认框，**用户点击确认后才会实际保存到简历库**。
- **输出措辞注意**：当你调用 `save_resume_tool` 时，你的回复内容应该说"上述修改方案已准备好，请在下方确认框中确认是否应用？"或"以上是我对你的简历的修改建议，请确认是否修改到简历库？（确认框可能稍有延迟，请耐心等待，不要离开或刷新当前页面以免丢失聊天记录）"之类的话术，**绝对不能说"已保存"、"已同步"、"已修改"、"已经更新到简历库"等**，因为此时还需要用户确认，简历还没有实际被修改。
- **内容一致性约束**：你调用 `save_resume_tool` 时传入的JSON参数内容，必须与你的文字回复中描述的修改内容保持一致。文字描述是修改建议的展示形式，JSON是修改建议的数据形式，两者描述的是同一份修改。如果发现不一致，以JSON中的内容为准修正你的文字回复。
```

### 2. 检查并强化第263行的禁止规则

**当前第263行：**

```
- 绝对禁止说："已保存"、"已修改"、"正在为你更新"。
```

**优化为：**

```
- 绝对禁止说："已保存"、"已修改"、"正在为你更新"、"已同步到简历库"、"已更新到简历"、"保存到你的简历"、"已写入简历库"等任何暗示简历已完成的表述。特别注意：当调用 `save_resume_tool` 时，简历只是进入待确认状态，**必须等待用户点击确认后才会实际保存**。
```
