# AI 首次提问引导语优化计划

## 需求概述

优化 AI 首次提问的结尾引导语，让用户知道可以优先回答哪个问题，并对重要信息进行加粗显示。

## 当前状态

1. **预设身份**（前端预制消息）：

   * 直接列出 2-4 个问题，没有引导语

   * 示例：`1. 你现在是什么专业？目前大几了？`

2. **自定义身份/上传简历**（LLM 生成）：

   * 直接列出问题，没有引导语

## 目标

1. **在问题列表后添加友好的引导语**，例如：

   > 💡 你可以先选择一个最想聊的告诉我，比如："我想先说说我的项目经历" 或 "先回答我关于第三个问题"

2. **对重要信息进行文本加粗**（使用 Markdown 语法 **文本**），例如：

   * 加粗问题内容：`1. 你的**目标岗位**是什么？`

   * 加粗关键概念：`你最有成就感的一件事是**什么**？（尽量用**数字**描述成果）`

### 2. 后端 Prompt 优化

**文件**: `resume_agent.py`

修改两个 Prompt：

#### 2.1 FIRST\_MESSAGE\_FROM\_RESUME\_PROMPT

```python

直接输出提问内容，用自然的口语化表达。
对关键信息使用 Markdown 加粗语法（如 **专业**、**项目** 等）。

在所有问题之后，添加一行友好的引导语，例如：
"💡 你可以先选择一个最想聊的告诉我，比如：'我想先说说我的**项目经历**' 或 '先回答我关于**第三个问题**'"

```

在所有问题之后，添加一行友好的引导语，例如：

用自然的口语化表达，不要太正式。
不要输出 JSON，不要有任何前缀。
