# 首页功能描述优化方案

## 优化目标

更新首页的核心功能展示，使其更清晰地传达产品价值，并明确目标受众群体。

## 功能模块优化

### 原功能 → 新功能（优化后）

| 原功能名称  | 新功能名称   |
| ------ | ------- |
| 简历创建   | 简历智能解析  |
| 目标岗位   | AI专家指导  |
| AI智能修改 | 边聊边改    |
| 排版导出   | 智能实时排版  |
| 求职辅助   | 一键导出PDF |

## 功能描述优化

### 1. 简历智能解析

**描述文案**：一键上传简历文档，AI自动识别并生成结构化简历。支持PDF、图片格式，精准提取教育背景、工作经验、技能证书等信息。

### 2. AI专家指导

**描述文案**：上传目标岗位描述的截图或文本，AI智能分析岗位要求与简历的匹配度，提供针对性的优化建议和竞争力评估。

### 3. 边聊边改

**描述文案**：通过自然对话与AI沟通，实时获取修改建议并自动应用到简历上。无需手动编辑，AI会根据对话内容智能优化简历。

### 4. 智能实时排版

**描述文案**：自动排版优化，实时预览效果。多种专业模板可选，一键切换不同风格适配不同岗位。

### 5. 一键导出PDF

**描述文案**：导出无水印专业版PDF简历，适配各招聘平台要求，提升投递效率。

## 目标受众（卡片切换样式）

在功能展示之后，使用卡片切换样式展示三类目标用户：

### 切换标签

* 寻找实习

* 秋招应届

* 跳槽转型

### 卡片内容（切换显示）

**寻找实习**：

* 标题：正在寻找实习机会的学生

* 描述：缺乏简历撰写经验，需要快速生成专业简历

**秋招应届**：

* 标题：准备参加秋季校园招聘的应届毕业生

* 描述：缺乏工作经验，需要突出教育背景和项目经历

**跳槽转型**：

* 标题：计划跳槽的职场白领

* 描述：需要优化现有简历，提升职场竞争力

## 实施步骤

1. 修改 `frontend/src/views/Homepage.vue` 中的功能卡片区域（核心功能部分）
2. 更新每个功能卡的标题和描述文案
3. 将"适用人群"模块改为卡片切换样式，包含三个切换标签和对应的内容卡片
