# 修复首次进入弹窗不显示的问题

## 问题分析

### 1. 代码问题：孤立的代码块
- `loadInitialData()` 函数 (第240行) 结构不完整
- 第368-427行的代码块位于函数外部，是孤立的代码，永远不会执行
- 这段代码引用了 `data` 变量，但该变量不在作用域内

### 2. 逻辑问题：简历数据判断不准确
- 后端 `load_resume` 对于新用户返回：`{"basics": {"photo": ""}, "parsing_status": "none"}`
- 前端判断逻辑：`const hasResume = resumeContent && Object.keys(resumeContent).length > 0`
- 由于返回数据中有 `basics` 键，`Object.keys().length` = 1，导致 `hasResume = true`
- 即使没有真实简历数据，也被认为"有简历"，所以弹窗不显示

## 修复方案

### 步骤1：删除孤立代码块
- 删除第368-427行的孤立代码

### 步骤2：在 loadInitialData 函数内添加正确逻辑
在 `loadInitialData()` 函数的正确位置添加：
1. 加载JD数据
2. 判断是否有简历（需要检查 basics 中是否有有效字段）
3. 加载对话历史
4. 如果既无简历也无对话，显示开始选择弹窗

### 步骤3：修正简历判断逻辑
```javascript
// 排除 parsing_status 和空的 basics
const { parsing_status, basics, ...rest } = data
const hasResume = basics && (basics.name || basics.target_position || Object.keys(rest).length > 0)
```
或者更简单：
```javascript
// 只检查核心字段
const hasResume = data.basics && (data.basics.name || data.basics.target_position)
```
